# Custos do Radar Unificando

Transparência: este projeto é gratuito para usuários, mas roda com custos reais.
As doações cobrem (ou ao menos reduzem) a conta mensal de infraestrutura e IA.

## O que a doação cobre

- Manutenção do servidor (VPS com Docker + nginx) e deploys
- Custo dos tokens de IA no chat (item mais volátil)
- PostgreSQL + Redis rodando na VPS
- Domínio `unificando.com.br`
- Novas fontes de vagas e melhorias
